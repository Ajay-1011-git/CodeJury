# Local design assets

Jersey 10 display font and variable Manrope body font are served locally, with no external font requests at runtime. Original SIL Open Font License notices are retained alongside the unmodified font files.

Sources: https://github.com/google/fonts/tree/main/ofl/jersey10 and https://github.com/google/fonts/tree/main/ofl/manrope (downloaded 12 October 2026).

The cloud, robot and gavel sprites are original hand-authored pixel grids expressed as integer SVG paths with crisp-edge rendering. They use the DESIGN.md palette; no smooth illustration, remote image service or image-generation dependency is required.
