# Anchored alternative continuations

Each new fixed-controller pre-action state now records an immutable anchor: exact episode hash, settled request IDs, last event ID and remaining budget. The continuation port refuses unanchored older episodes, unknown forced options and budget expansion.

Every alternative gets a separate ledger/run, fresh audit cache and real future model/tool dispatches. Historical evidence is explicitly inherited, not fabricated or charged as newly executed work. It imports only the anchored requests and registered facts present before the action, retains the original bounded initial fixer views, reconstructs prior audit/challenge/search/revision state and carries the same remaining budget and final reserve. Future tests or generations are excluded. Parent snapshots remain unchanged.

Three trusted CPU checks execute alternative continuations and verify different outcomes, equal starting budgets, immutable parents and exclusion of future tests/receipts. They are labeled fixture mechanics, never native training evidence. Actual learning rollouts must wait for the frozen trained Critic registry and newly anchored native collection.

The guarded learned-Judge runtime is implemented and tested. It checks current state/option/evidence IDs and rechecks prerequisites after generation. One schema retry is allowed, at most eight decisions are charged, and any fixed fallback is explicitly recorded. No trained Judge card or measured Judge action labels exist yet. Private scoring will occur only after each alternative's final source commitment; labels will never enter continuation prompts.
