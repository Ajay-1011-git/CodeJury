# Anchored alternative continuations

Each new fixed-controller pre-action state now records an immutable anchor: exact episode hash, settled request IDs, last event ID and remaining budget. The continuation port refuses unanchored older episodes, unknown forced options and budget expansion.

Every alternative gets a separate ledger/run, fresh audit cache and real future model/tool dispatches. Historical evidence is explicitly inherited, not fabricated or charged as newly executed work. It imports only the anchored requests and registered facts present before the action, retains the original bounded initial fixer views, reconstructs prior audit/challenge/search/revision state and carries the same remaining budget and final reserve. Future tests or generations are excluded. Parent snapshots remain unchanged.

Three trusted CPU checks execute alternative continuations and verify different outcomes, equal starting budgets, immutable parents and exclusion of future tests/receipts. They are labeled fixture mechanics, never native training evidence. The selected native Critic and a newly anchored 80-train/20-validation collection now supply actual continuation inputs. Exact controller, view, execution and tool implementation hashes are checked at restoration; changed continuation implementations are refused.

The guarded learned-Judge runtime is implemented and tested. It checks current state/option/evidence IDs and rechecks prerequisites after generation. One schema retry is allowed, at most eight decisions are charged, and any fixed fallback is explicitly recorded. A trained Judge card is not released yet. The native pilot committed 22 actual alternatives across four states (one train base and one validation base). Only after every commitment existed did private assessment score the selected source. Three states supplied distinguishable action labels; an uncertain action tie was excluded at the declared 0.001 margin. Forty-four close ties were excluded; accepted labels cover 40 training states / 38 bases and 14 validation states / ten bases. Two consistent ID variants per state produce 80 training and 28 validation chats, with no new independent cases.

Private labels rejoin the original commitments, exact fork snapshots, saved source and genuine assessment executions. Cancelled, infrastructure and invalid alternatives cannot produce training labels; close action ties are excluded. All weights, labels and private receipts remain in ignored artifacts.
