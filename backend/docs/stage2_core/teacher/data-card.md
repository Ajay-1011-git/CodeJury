Actual collection: **40 proposals / 20 authorized TRAIN bases**, two proposals per base. The account preflight plus collection used **41 HTTP attempts**, with **$0.0063987 reported usage**, zero unknown charges and a $1 / 60-attempt cap. No extra remote collection is planned for this A pilot.

Execution/format filtering accepted **22 distinct targets covering all 20 bases**. Rejections: 16 duplicate solutions within the same base, one call outside the pilot's reviewed scope, and one response with unreviewed assumptions. Duplicates remain archived; they are not counted as distinct teacher examples. The original assumption-bearing response was preserved, then the prompt explicitly required an empty assumptions array and plain executable code. No final or validation data was sent remotely.

Each accepted repair preserves the function signature and requirement IDs, passes supplied tests and private TRAIN assessment, and agrees with the locally executed reviewed reference on bounded domain edge cases. Input mutation, exceptions and output-codec failures reject a target. All candidate and reference calls run in the dedicated ARM64 Docker runner with no host mounts, no network, an unprivileged user and bounded resources. This is empirical support on finite tests, not proof for every possible input.

The real local tokenizer/MLX chat processor checks exact runtime prompt prefix and assistant completion masking, total context at most 4096, a 1024-token runtime completion reserve, and a completion at most 1024 tokens. Only frozen A runtime-visible input becomes the student prompt. The teacher sees buggy source, reviewed contract/interfaces/domain, approved requirements and supplied tests; it never sees correct source, private training test cases, local validation/final cases or dataset target fields.

The immutable SFT export has **100 sampled TRAIN records: 60 existing verified records plus 40 teacher-derived records**, with 20 local validation records. Teacher oversampling from 22 unique targets is disclosed in the manifest; it does not create additional unique evidence. Replay covers all 40 original TRAIN bases to reduce forgetting. Provenance, record/target/receipt hashes and the source split seal accompany the export. Near duplicates are checked within base; family/base split boundaries remain the frozen original boundaries.

Limitations: small synthetic integer/list corpus; no new independently reviewed base problems or revision-state examples; restricted pilot call scope; teacher quality does not establish student quality. Only matched local executable validation can support candidate selection. All raw prompts/targets/assessment artifacts remain in ignored local artifacts; public reports contain aggregate evidence only.
